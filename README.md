# Palitos: Arena

Shooter de palitos visto desde arriba, para Android. Vos contra 3 bots, partidas de 3 minutos.

## Descargar

Andá a **Releases** (a la derecha en esta página), descargá `PalitosArena.apk` e instalalo.
Android te va a pedir permiso para instalar apps de fuentes desconocidas: es normal para apps que no vienen de Play Store.

## Cómo se juega

- Joystick izquierdo: moverte
- Joystick derecho: apuntar (empujalo a fondo para disparar)
- Pasá por encima de las armas para agarrarlas

## Cómo se compila

Cada vez que se sube un cambio a `main`, GitHub Actions compila el APK y lo publica en Releases.
El juego está en `app/src/main/assets/index.html`.
